**Nome:** João Victor Alves Silva

**Curso:** Ciências da Computação

Este repositório foi criado para praticar controle de versões, commits, branches e Pull Requests no GitHub. 
## Objetivo do repositório

Este projeto tem como objetivo praticar os fundamentos de controle de versões utilizando o GitHub. A atividade inclui o registro de alterações por commits, o desenvolvimento em uma branch separada, a revisão por Pull Request e a incorporação das mudanças à branch principal.
